# Dart Grade Calculator (Console App)

A basic console-based Grade Calculator for statistical analysis

## Features

- Add grades between 0 and 100
- View all saved grades
- Calculate:
  - Number of students
  - Average grade
  - Highest grade
  - Lowest grade
  - Grade distribution (A, B, C, D, F)
- Input validation:
  - Rejects non-numeric input
  - Rejects grades outside 0–100
- Simple text menu loop so you can keep using the app until you exit
